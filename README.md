## Создание простейших компиляторов для софт-процессоров

В рамках семинара студентам предложено реализовать 3 программных модели процессоров и 3 компилятора.

Необходимо уметь компилировать все mpy-программы из репозитория. Разрешается сверяться с эталонными результатами компиляции из `asm`. При серьезных затруднениях можно подсмотреть решение в `solutions`.

### Дополнительные упражнения

1. Убрать метки из скомпилированного кода, перенумеровать адреса и заменить ссылки в JZ/JMP. 
1. Заменить символические Mem-адреса на числовые, без пропусков.
1. Вывести статистику по числу скомпилированных и выполненных команд, используемому программой объему памяти/стека/регистрового файла.
1. Поддержать вывод кода в текстовом asm-формате.
1. Генерировать более короткий код для конструкции `if`.

### Абстрактный синтаксис входного языка

Подмножество Python, разбор с помощью модуля `ast`.

```bnf
<program>     ::= <block>
<block>       ::= <statement>*
<statement>   ::= <assign>
                | <out>
                | <if>
                | <while>
<assign>      ::= Assign(<name>, <expr>)
<out>         ::= Out(<expr>)
<if>          ::= If(<expr>, <block>, <block>)
<while>       ::= While(<expr>, <block>)
<expr>        ::= Constant(<integer>)
                | Name(<name>)
                | BinOp(<binop>, <expr>, <expr>)
<binop>       ::= Add | Sub | Mul | Eq | Lt | Le
```

### Процессорные архитектуры

* Архитектура память-память.
* Стековая архитектура.
* Регистровая архитектура.

**ISA машины память-память**

```
┌───────┬───────┬──────┬──────┐
│ op    │ dst   │ src1 │ src2 │
├───────┼───────┼──────┼──────┤
│ LI    │ Mem   │ Imm  │ -    │
│ MOV   │ Mem   │ Mem  │ -    │
│ ADD   │ Mem   │ Mem  │ Mem  │
│ SUB   │ Mem   │ Mem  │ Mem  │
│ MUL   │ Mem   │ Mem  │ Mem  │
│ EQ    │ Mem   │ Mem  │ Mem  │
│ LT    │ Mem   │ Mem  │ Mem  │
│ LE    │ Mem   │ Mem  │ Mem  │
│ JZ    │ Label │ Mem  │ -    │
│ OUT   │ -     │ Mem  │ -    │
│ JMP   │ Label │ -    │ -    │
│ LABEL │ Label │ -    │ -    │
└───────┴───────┴──────┴──────┘
```

**ISA стековой машины**

```
┌───────┬───────┬───────┬───────┐
│ op    │ dst   │ src1  │ src2  │
├───────┼───────┼───────┼───────┤
│ PUSH  │ Stack │ Imm   │ -     │
│ LD    │ Stack │ Mem   │ -     │
│ ST    │ Mem   │ Stack │ -     │
│ ADD   │ Stack │ Stack │ Stack │
│ SUB   │ Stack │ Stack │ Stack │
│ MUL   │ Stack │ Stack │ Stack │
│ EQ    │ Stack │ Stack │ Stack │
│ LT    │ Stack │ Stack │ Stack │
│ LE    │ Stack │ Stack │ Stack │
│ JZ    │ Label │ Stack │ -     │
│ OUT   │ -     │ Stack │ -     │
│ JMP   │ Label │ -     │ -     │
│ LABEL │ Label │ -     │ -     │
└───────┴───────┴───────┴───────┘
```

**ISA регистровой машины**

```
┌───────┬───────┬───────┬───────┐
│ op    │ dst   │ src1  │ src2  │
├───────┼───────┼───────┼───────┤
│ LI    │ Reg   │ Imm   │ -     │
│ LD    │ Reg   │ Mem   │ -     │
│ ST    │ Mem   │ Reg   │ -     │
│ ADD   │ Reg   │ Reg   │ Reg   │
│ SUB   │ Reg   │ Reg   │ Reg   │
│ MUL   │ Reg   │ Reg   │ Reg   │
│ EQ    │ Reg   │ Reg   │ Reg   │
│ LT    │ Reg   │ Reg   │ Reg   │
│ LE    │ Reg   │ Reg   │ Reg   │
│ JZ    │ Label │ Reg   │ -     │
│ OUT   │ -     │ Reg   │ -     │
│ JMP   │ Label │ -     │ -     │
│ LABEL │ Label │ -     │ -     │
└───────┴───────┴───────┴───────┘
```
